# Run It On Your Own Computer

We The Citizens is a program you run, not a service you sign up for. The default install puts the entire product on your own computer: you open `http://localhost:4444/` in a browser, and everything you record is written as ordinary files in a folder you own. No account, no database, and nothing leaves the machine unless you decide to send it.

## What it does

There are two modes, and they are the architecture rather than a feature list. **Individual Mode** is the default and is fully local. Everything the app knows is stored as readable files under one directory on your machine, outside any cloud-synced folder, and the person at the keyboard is a built-in **default user**, so the app is completely usable with nobody signed in. **Community Mode** is optional aggregation layered on the same software: it pools many citizens' decisions and shows each person the difference between their own view and the group's.

The data is kept in formats a person can open. Structured YAML holds the settings and all four pillars — your positions, your drafted law, your value system, your evidence chains. The reasoning layers are plain text and the logs are append-only text. Every write is atomic and every file is validated on read, so a bad hand-edit is logged and falls back to a typed default rather than crashing a page. That exists for one reason: a citizen is allowed to open their own data in a text editor.

Pull the machine off the internet and every pillar still works. The backend is a local process talking to the local filesystem; the browser talks to it over loopback. Nothing is transmitted unless you choose to publish.

The whole product degrades rather than fails, and each degradation is named out loud:

* **No database** means flat files. That path is a complete, supported implementation, not a demo mode, and it is never removed.
* **No AI credentials** means a deterministic offline reasoner instead of an error screen.
* **No movement data on the machine** means one screen stating exactly what is missing and handing over the command that fixes it — not twelve pages each quietly saying "nothing here".

Everything you cast is also appended to a local **hash chain**: small blocks under your own directory, each committing to the one before it, with no network, no wallet and no currency. Recomputing the chain reveals any altered block. That is what lets you prove what you decided and when, and lets a person who receives something you published confirm it has not changed since you cast it.

The hosted install at [app.WeTheCitizens.io](https://app.WeTheCitizens.io/) runs the identical code with one persistence driver pivoted. A local result and a hosted result are the same arithmetic.

## The goal it serves

A tool you own outright cannot be switched off, cannot be quietly changed underneath you, and holds no central record of what you read or concluded. That is not a privacy nicety. A movement telling citizens they should not have to take institutions on faith cannot turn around and require them to trust a server it controls.

[The problem this site describes](/docs/the_problem/overview) is that the decisions being made are not answerable to the people they land on, and that the evidence for it sits in [the official record](/docs/open_data/the_sourcing_rule) where anyone can look. If the software doing that lookup lives only on somebody else's machine, your ability to check depends on their permission, their uptime, and their continued interest in letting you. Local-first removes that dependency.

What is *not* collected matters just as much. A central system logging which laws you read, which officials you looked up, and what you concluded would assemble exactly the kind of behavioural file [this movement objects to elsewhere](/docs/no_social_credit/overview). [Your positions and your reasoning](/docs/decisions/overview) stay on your disk and are never proposed to anyone, so they cannot be leaked, subpoenaed or sold — [the charter](/docs/the_movement/charter) written into the file layout rather than promised in a policy page.

## What keeps it honest

* **The local path is a tested configuration, not a courtesy.** Running with no database and no network is a supported way to run the product, and it does not get dropped when the hosted install gets more convenient.
* **It does not claim to protect you from your own machine.** The state directory is created private to your user account, but the files are plain files. Anyone who can log in as you can read them.
* **The hash chain is not an external blockchain and does not pretend to be.** No consensus, no mining, no currency. It proves a record has not changed since it was written; it does not prove the record was correct. Publishing the latest chain hash publicly, so the timestamps are independently witnessed, is opt-in and off by default.
* **Publishing is always an explicit act.** There is no background sync. Until you send something, the files are inert local data.
* **The hosted copy differs on one thing.** A shared install has no default user and requires signing in, because a shared machine is not your machine.
