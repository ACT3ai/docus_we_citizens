# Open Data

Citizens can re-run the numbers themselves and get the same answer.

* The data behind trust scores, candidate records and community votes is open.
* Citizens can re-run the numbers themselves and get the same answer. That is the only meaningful definition of a checkable claim.
* Where data is private by design — a citizen's own local files — we say so plainly instead of pretending everything is public.
