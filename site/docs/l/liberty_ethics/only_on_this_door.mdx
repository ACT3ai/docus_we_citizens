# Why This Is the Only Door That Carries Them

One file, one domain, one audience. Two audiences never share a page.

* The .io stays out of any one ethical tradition, so it can stay the neutral lobby it was built to be.
* The other party doors speak their own communities' language, and it is not this one.
* Christian values are exclusive to the Republican door and never appear here — the same rule, running in the other direction.
* One file, one domain, one audience. Blending two audiences' messaging on a page serves neither of them.
