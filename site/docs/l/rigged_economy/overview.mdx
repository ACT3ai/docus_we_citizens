# Removing the Rigged Economy

:::tip[The question this area answers]
**What is your economic plan?**
:::

Removing the rigged economy is a goal shared by all four doors, and each community writes its own version of it. This is the liberty movement's version, written by libertarians, in their own language.

* **The means:** remove the rigged layer — the subsidies, the carve-outs, the regulatory capture, the bailouts.
* **The end:** an economy that is ethical and clean.
* **The test:** it has to be ideal for workers too. That is stated here, on this door, and it is not a concession to anybody.

## In this area

* [An Ethical, Clean Economy That Is Ideal for Workers](./ideal_for_workers.mdx) — Removing the rigged layer is the means. The clean economy is the end.
