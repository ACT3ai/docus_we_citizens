# The Libertarian Community's Own Package

The community creates the package. We give the process and the tools.

* Libertarians create **their** package for how to remove the rigged economy. Not a draft handed to them for approval.
* It is built by [community-based voting and collaboration](/docs/l/community_voting), the same way everything else on this door is built.
* We give the process and the tools. The content is theirs.
