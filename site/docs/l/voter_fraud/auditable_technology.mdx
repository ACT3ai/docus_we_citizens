# Auditable Technology, So Nobody Has to Trust a Vendor

Open, auditable technology is the only kind an election can be built on.

* Open, auditable technology — open source, open data — so nobody has to trust a vendor.
* Verifiable by any citizen, not only by an authorized official with special access.
* This connects directly to [Open Source, Open Data, Open AI](/docs/l/open_everything): an election system nobody can inspect is not an election system we accept.
