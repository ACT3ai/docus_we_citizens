# Words We Use

The phrases that belong on this door.

* **Democratic socialists.** Always the full phrase, never socialists on its own.
* **Working people**, **workers**, **the citizen base**.
* **Political challengers**, **incumbents controlled by special interests**, **not controlled by special interests**, **meritocracy**, **works for citizens**, **cannot be co-opted**.
* **Money in politics**, **Citizens United**, **new colonialism**.
* **The rigged economy**, **an ethical, clean economy**, **ideal for workers**.
