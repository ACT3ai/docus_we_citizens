# Removing the Rigged Economy

:::tip[The question this area answers]
**What is your economic plan?**
:::

Removing the rigged economy is a goal shared by all four doors, and each community writes its own version of it. This is the Democratic Socialist community's version, written by democratic socialists, in their own language.

* **The means:** remove the rigged layer that sits between working people and a working economy.
* **The end:** an economy that is ethical and clean.
* **The headline, not the footnote:** it has to be ideal for workers.
