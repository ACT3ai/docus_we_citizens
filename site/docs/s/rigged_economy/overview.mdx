# Removing the Rigged Economy

:::tip[The question this area answers]
**What is your economic plan?**
:::

We do not hand you an economic plan, and we are not going to argue with the one you have. Democratic socialists write this one, in their own language, and this is where they write it.

* **The means:** remove the rigged layer that sits between working people and a working economy. Every carve-out in it was written by somebody who benefits from it.
* **The end:** an economy that is ethical and clean.
* **The headline, not the footnote:** it has to be ideal for workers.

All four doors are removing the same rigged layer. Each community writes its own version of how, and this one is yours.

## How a complaint becomes a bill

* **A problem has to be fixable to count.** Every problem carries a statement of what the world looks like once it is fixed. A problem with no statable fixed state is a complaint, and it does not go in.
* **Then it gets traced to the instrument.** Which enacted law carries the carve-out, and who voted it in.
* **Then the fix gets written.** Legislative language a member could file tomorrow, built from what citizens actually voted for rather than from what a lobbyist put in front of a staffer.
