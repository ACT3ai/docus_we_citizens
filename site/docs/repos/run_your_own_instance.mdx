# Run your own instance

## Locally, for yourself

The normal way to use We The Citizens is on your own computer. Clone the app, clone the record, start
it, and open it in a browser. Your positions, your value systems and your evidence chains are flat
files on your own disk. No server is required, and nothing is shared unless you choose to share it.

Login is optional in this mode: a default user can use everything. Identity only starts to matter when
you join a community or publish something.

## Hosted, for a group

The same application runs as a central server for a community that would rather not have everybody
install something. In that mode login is required and the public read tier applies to visitors.

## Forking

If you disagree with how the movement is run, fork it. Take the code, take the record, run your own
with your own admins and your own list, and argue with us in public using the same data.

This is stated as an invitation rather than tolerated as a risk, because it is the only credible answer
to *what stops you from becoming the censor?* Every other answer is a promise, and the movement's whole
position is that promises from unaccountable institutions are worth nothing.

The record being independently clonable is what makes the fork real. A fork of the software alone would
still depend on us for the facts.

## The paired social network

Fixes a citizen decides on can be published into the movement's decentralized social network, where
others can read, evaluate and build on them. It is a separate property with its own repositories, built
on the same principle: your keys, your followers, your words.
