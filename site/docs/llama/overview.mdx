# The Llama Award

<CTA />

The **Llama Award** is the Monkey's mirror: a single number, 0 to 100, published as a **percentage of
that award**, for how far a named politician's own recorded acts advanced the laws that **repair**
representative democracy.

*"This [voting record](/voting_records/overview/) was given a 72% Llama Award."* Here, higher is better.

## Why the opposite award has to exist

Because a damage number alone is a smear machine.

Without a repair award, the only thing the movement could ever publish about a person is how much harm
they did, and the best possible outcome available to anybody would be a zero — the absence of a
finding. A movement that can only accuse has no way to say *this person is worth re-electing*, and it
would deserve the suspicion that gets it.

The Llama is how the record can say something good, on the same evidence, by the same arithmetic.

## Same machinery, one different table

The Llama and the Monkey share almost everything: the same eligibility rules, the same definition of
an act, the same twelve-category classifier, the same weighted-average equation. They differ in
**one** place — the table of scores and weights each category carries.

That shared machinery is deliberate. Two separately-tuned systems would drift, and the day they
disagreed nobody could say which was wrong.
