## How a complaint becomes a bill

* **A problem has to be fixable to count.** Every problem carries a statement of what the world looks like once it is fixed. A problem with no statable fixed state is a complaint, and it does not go in.
* **Then it gets traced to the instrument.** Which enacted law carries the carve-out, and who voted it in.
* **Then the fix gets written.** Legislative language a member could file tomorrow, built from what citizens actually voted for rather than from what a staffer drafted.
