# Open Data, Open Source, Open AI

This is what makes the meritocracy claim verifiable instead of just asserted.

* **Open source.** The code that runs the voting, the matching and the scoring is open, so anyone can read it and confirm it does what we say.
* **Open data.** The data behind trust scores, candidate records and community votes is open, so a citizen can re-run the numbers and get the same answer. Where data is private by design — a citizen's own local files — we say so plainly.
* **Open AI.** Open models where we can, open prompts and open method always. A citizen can see why the AI concluded what it concluded, and disagree with it. AI advises citizens here; it never decides for them.
* This is what makes the meritocracy claim verifiable instead of just asserted.
