# Our Board of Directors

:::tip[The question this area answers]
**Who governs this?**
:::

A board of directors exists at the .com level, and this door has one. The non-partisan side does not.

* It is a real governance body, so we describe it accurately and never overstate it.
* Partisan governance belongs with the partisan community.
* The .io's top-level plan stays at the high level: finding the best candidates able to keep working for citizens.
