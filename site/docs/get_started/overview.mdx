# Get Started

:::tip[The question this area answers]
**How do I get it running?**
:::

## Two ways in

**Hosted** — go to [app.WeTheCitizens.io](https://app.WeTheCitizens.io). Nothing to install. Login is
required, and logged-out visitors can read the whole movement first.

**On your own computer** — the way it was designed to be used. Everything local, login optional, and
nothing leaves your machine unless you publish it.

## What happens the first time

Three things, in this order, and none of them takes long:

1. **Mode selection.** One screen, one question: is this install a central server, or your own
   computer? Your answer is written to config and the screen never appears again.
2. **The movement data.** The app asks you to clone the public record, and gives you the exact command
   for your machine. It re-checks on its own — paste the command in a terminal, switch back to the
   browser, and you are already in.
3. **Sign in, or do not.** On your own machine you can stay the anonymous default user indefinitely.

## Also available

**`wtcx`** — the command-line interface, for people who would rather not click. It is built for the
work that comes in batches.

**An MCP server** — so an AI assistant can query the movement's record directly, through a typed tool
catalog with its own guard rails, rather than by scraping the web app.
