# Use it hosted

Go to **[app.WeTheCitizens.io](https://app.WeTheCitizens.io)**. That is the whole install step.

## What you can do before signing up

Read the entire movement. The public read tier covers the rosters, the awards and their derivations,
the problem catalog, all four law libraries, the rubrics, and the data.

There is no teaser wall. A visitor who never signs up still gets the argument in full, because a
movement that hides its reasoning behind a signup form is asking for exactly the deference it says
nobody has earned.

## What requires an account

Writing. Proposing a problem, reporting a problem law, recommending a leader, giving feedback on a
record, logging an action, joining a community.

Those controls **render normally** — never greyed out, never hidden. Clicking one takes you to sign up,
**remembers what you were doing**, and returns you to it when you are done. An invitation, not a wall.

## Signing in

Federated sign-in with Google. The admin role is granted by signing in with an address in an
administrative domain — it is not something a user can request or be talked into.

## Hosted vs local — the honest comparison

| | Hosted | Your own computer |
|---|---|---|
| install | none | clone two repositories |
| login | required | optional |
| your positions and chains | on the server | flat files on your disk |
| works if we disappear | no | yes |
| good for | trying it, groups | the way it was designed |

Hosted is the right first step and a reasonable permanent home for people who want the movement's
record more than the reasoning tools. If you intend to do serious work — build chains, apply your own
value system, keep positions over years — run it locally.

## What the hosted install does not change

The record is the same public repository either way, the awards are the same published equations, and
admins still approve everything. Hosting changes where the process runs, not what it does.
