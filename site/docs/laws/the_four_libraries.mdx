# The four libraries

## Problem laws — *what is doing the damage*

Enacted law, in force, that the movement holds responsible for taking representative democracy apart.
Each carries a badness rating, its root causes, and its sources.

This library is the input to the [Monkey Award](../monkey/overview.mdx), which is why admission is
deliberately hard: every law added changes what the movement publishes about hundreds of named living
people at once.

→ [Problem Laws](../problem_laws/overview.mdx)

## Fixing the law — *how a complaint becomes legislation*

Not a library of records but the **process**: problem → root causes → drafted sections → a coverage
matrix showing which causes a draft closes and which it visibly does not.

This is Pillar 2, and it is the answer to *"fine, what would you do instead?"*

→ [Fixing the law](../fix_laws/overview.mdx)

## Fix bills — *what we would file*

Language the movement wrote that nobody has filed. Real sections, real definitions, real enforcement,
with the root causes each section closes and the ones it leaves open.

The library's worked example is a four-bill disclosure package, each bill enforceable on its own and
only closing the whole argument together — because different institutions refuse differently and one
statute drafted against both refusals would have to be vague about each.

→ [Fix Bills](../good_bills/overview.mdx)

## Good laws — *what somebody actually tried*

Instruments that would repair democracy, recorded whatever happened to them: passed, voted down, or
never allowed a vote. Admission is by eight structural tests — repeal, restore, transparency,
accountability, franchise, due process, speech, purse.

This library is the input to the [Llama Award](../llama/overview.mdx).

→ [Good Laws](../good_laws/overview.mdx)

## Reading across all four

The libraries are most useful together. Start at a problem, follow its root causes to the fix bills
that claim to close them, check the coverage matrix for what nobody has closed, then look at the good
laws somebody already filed against the same problem and what happened to them.

That path — problem to remedy to what was actually attempted — is the whole argument the movement
makes, and it is walkable in about five clicks.
