# Removing Voter Fraud for Good

:::tip[The question this area answers]
**Can I trust the count?**
:::

You have to be able to believe the count. Without that, nothing else on this platform matters.

* **The goal is not fraud reduced, or fraud investigated. It is fraud made structurally impossible.**
* **Checkable by an ordinary citizen** — every step from registration through certification, not only by an authorized official.
* **Open, auditable technology**, so nobody has to trust a vendor. An election system nobody is allowed to inspect is not one we accept.
* **We ask for verifiable elections, not for anyone's word — including ours.** We do not make claims about a specific fraud we cannot source.

## How this gets measured, and how we hold ourselves to it

* **Degrading the vote is a chargeable act on its own.** An instrument that damages the integrity or accessibility of the vote, or the auditability of the count, qualifies on those grounds alone — and every entry has to name an instrument and a section, never just a topic.
* **Our own code and data are open**, so the arithmetic we publish about elections is something you can try to break rather than something you have to accept.
* **Election interference of any kind is absolute for us.** Nothing we ask a citizen to do goes anywhere near it, and there is no "but they did it first" exception. The whole argument here is that the people in power are the ones breaking the rules. That argument only holds if we do not.
