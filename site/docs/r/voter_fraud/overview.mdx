# Removing Voter Fraud for Good

:::tip[The question this area answers]
**Can I trust the count?**
:::

You have to be able to believe the count. Without that, nothing else on this platform matters.

* **The goal is not fraud reduced, or fraud investigated. It is fraud made structurally impossible.**
* **Checkable by an ordinary citizen** — every step from registration through certification, not only by an authorized official.
* **Open, auditable technology**, so nobody has to trust a vendor. An election system nobody is allowed to inspect is not one we accept.
* **We ask for verifiable elections, not for anyone's word — including ours.** We do not make claims about a specific fraud we cannot source.
